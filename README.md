# learn ai design with phoebe

Two tracks into design where taste still decides, by Phoebe Fu.

**Live:** https://phoebefu6.github.io/learn-ai-design-with-phoebe/

Generation got cheap, so judgement got expensive. This course teaches the half of taste that is
measurable, the half that is not, and how to tell a stakeholder which is which.

- **Leader track (6 x 45 min)** - for design, brand and creative leads: what actually changed, the
  critique standard, the tool and workflow map with real plan and credit gates, IP and provenance
  risk, craft and careers, and a rollout measured on quality rather than volume.
- **Designer track (10 x 45 min)** - for working designers: one running feature, Cadence's shared
  summary, taken from constraint brief to a spec'd, system-conformant, handed-off screen set.

## The critique lab

`assets/design-live.js` renders a real screen and **measures it for real** - WCAG 2.1 relative
luminance for contrast, `getComputedStyle` for spacing and type sizes, HSL conversion to count hue
families. Toggle the five craft levers and the score climbs **17 → 32 → 46 → 66 → 86 → 100**. Then
press the sixth, "add colour", and watch a finished screen lose 19 points.

The starting draft is a scripted composite of unbriefed generator output. Every number after that is
measured live in your browser.
